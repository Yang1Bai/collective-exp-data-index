The positive scientific thesis is fixed: neighboring experimental domains can
provide useful and complementary information when sources are qualified,
matched to the endpoint, preserved as independent proposals, and protected by
wrong-source controls. KIT predictive transfer, Caltech external source
rankings, and the diagnostic neighbor portfolio provide component-level proof
of feasibility. The added CCA family-first audit tests whether that portfolio
recovers distinct high-value regions rather than repeated within-component
entities, includes the failed multiplicative local gate, and supplies an
outcome-unseen freeze protocol. That protocol has now been executed on
Starrydata and TRI: neither target passes its complete gate, and the pooled
effect is null and heterogeneous. The artifact-gated map therefore retains
positive, null, harmful, and unresolved regions and demonstrates abstention
rather than a general transfer law. The integrated strategy is not a
prospective discovery-acceleration result.
