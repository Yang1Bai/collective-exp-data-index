# Clean second-family replacement after the acid-OER metadata gate

The Caltech acid-OER target was assessed from outcome-free composition and
plate metadata after the accidental-access exclusions. It retained 181
entities and 40 composition clusters, but plate 5414 retained only eight
entities, below the predeclared minimum of 20 per evaluation plate. It is
therefore downgraded before remaining outcomes are opened and cannot satisfy
CS10 or CS12.

The replacement is the Caltech/Toyota OER active-learning benchmark at DOI
`10.22002/D1.1345`. Public record metadata states that it contains four
composition sets, composition arrays, and an OER overpotential figure of merit.
No target file or target value was downloaded or inspected before this
replacement freeze. The same source families, wrong controls, prediction
baselines, CCA policies, card requirements, and multi-target inference rules
from `outcome_unseen_neighbor_validation_program.json` are retained.
