# AI object-layer prompt and usage boundary

The draft object layer was generated from the following prompt and saved as
`assets/knowledge_borrowing_object_layer_ai_draft.png`.

> Create one publication-grade scientific illustration layer for a Nature
> Machine Intelligence / Nature Materials research figure. Use a wide white
> canvas with no text, numbers, legends, captions or watermarks. Show three
> data-rich neighbouring experimental programmes (a crystalline ionic solid,
> a catalyst-coated electrode and a molecular electrolyte), a selective
> four-stage knowledge bridge in which most paths fail and one teal path
> survives, and a sparse recipient landscape with measured blue samples and
> orange outlined OOD candidates. Use a restrained navy, teal, orange, coral
> and grey palette, generous whitespace and scientific rather than dashboard
> visual language.

The generated raster is a composition study only. It is **not embedded in the
submission figure**. Scientific objects, paths, labels and quantitative panels
were redrawn deterministically in Python as vector primitives. No generated
data marks or generated numerical annotations enter the final figure.
