# Core-story terminology ledger

| Canonical term | First-use definition | Avoided variants or ambiguity |
|---|---|---|
| out-of-distribution (OOD) | a complete held-out system or candidate region not represented by the recipient training observations | extrapolative area, far region, unknown space |
| falsification-gated knowledge borrowing | the full workflow that qualifies a directed edge, transfers a declared relation or score, tests matched falsifiers, and routes the result to prediction, screening, or abstention | endpoint-routed transfer, generic transfer learning |
| neighbouring experimental programme | a potential donor sharing a recipient-available representation and a falsifiable physical or experimental relation to the recipient endpoint | adjacent domain when no task-specific relation is stated |
| donor | the directed task that supplies a learned relation, prediction, or ranking | source database when only part of the database is used |
| recipient | the data-poor task whose held-out outcomes define utility | target database when the task is a subset or endpoint |
| knowledge-borrowing edge | one declared donor-to-recipient application evaluated at one decision endpoint | transfer pair, knowledge-transfer link |
| transferred object | the specific information crossing the boundary: a relation, calibrated prediction, or ordinal score | feature injection as a universal description |
| experimental state | formulation, processing, phase, temperature, test mode, concentration, or other conditions needed to interpret a measurement | metadata when the field is scientifically active |
| recipient anchor | one measured recipient example used for local calibration or adaptation and excluded from evaluation | few-shot label without explaining its role |
| ordinal score | a donor-derived candidate ordering that is not interpreted as a calibrated property value | prediction when only rank is validated |
| matched falsifier | a shuffled, wrong-property, or architecture-matched donor used to test specificity | random control without describing what is matched |
| abstention | rejection of an edge that fails any required endpoint-specific gate | null as though it were missing evidence |
| root-mean-square error (RMSE) | held-out numerical prediction error | loss when reporting scientific performance |
| Spearman rank correlation \(\rho\) | held-out agreement in candidate ordering | rank accuracy |

Dataset and programme names are expanded at first use. Abbreviations such as
oxygen evolution reaction (OER) and ultimate tensile strength (UTS) are used
only after expansion.
